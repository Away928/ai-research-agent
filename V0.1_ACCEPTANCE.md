# Research Agent v0.1 — Validation and scope

**Current release:** [v0.1.3](https://github.com/Away928/ai-research-agent/releases/tag/v0.1.3) · **Showcase:** [Static demo](https://away928.github.io/ai-research-agent/)

This page distinguishes what has been tested from what still needs evidence. It is not a claim of production-ready financial analysis.

## Verified in v0.1

| Area | Verification | What it does *not* establish |
| --- | --- | --- |
| Offline Python workflow | 190 offline/unit tests, including synthetic four-stage tests and financial-field checks | Accuracy of live source data or market predictions |
| Interactive UI | Streamlit AppTest for Demo and mocked real-research entry | Public multi-user deployment or working real LLM credentials |
| CLI | `--help` and mocked failure/success paths | Guaranteed provider uptime |
| Static HTML | Single-file export and offline browser/static-content checks | A live AI agent running in the browser |
| Data quality | Internal FIN marker consistency; selected source/reporting-period validations | Comprehensive original-filing audit |

The source and release also undergo automated [GitHub Actions](https://github.com/Away928/ai-research-agent/actions) checks on multiple Python versions. Public-data source collection has been observed working in one bounded local test; that does not establish future provider reliability.

## Reproduce the offline acceptance checks

Use Python 3.12 in a clean virtual environment:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/verify_v01.py
```

The verification script runs offline tests, simulated UI entrypoints, CLI startup and synthetic HTML export. It does not require paid model credentials or live financial APIs.

## Current release boundary

- The [static browser showcase](https://away928.github.io/ai-research-agent/) is public and does not require login.
- Streamlit defaults to interactive synthetic-only mode, with a separately enabled private research gate. Public anonymous availability still requires the owner to set the Streamlit Cloud app's *Sharing* setting to public; see [deployment instructions](STREAMLIT_DEPLOYMENT.md).
- The hosted app's accessibility is an **external deployment state**, not something CI alone can assert.
- Real industry research is best-effort and depends on third-party providers, optional LLM access and independent checking of all factual claims.
- Model-generated research can be incomplete or wrong, and the project does not place trades or provide investment advice.
- The current public Git tree was created from reviewed source files. Previously accessible GitHub objects or external clones may still exist despite a cleaned branch history.

For the user-facing walkthrough, see [Demo Guide](DEMO_GUIDE.md).
